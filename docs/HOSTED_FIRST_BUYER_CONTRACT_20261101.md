# Hosted account admission (development candidate)

Canonical HTTPS origin and immutable tenant identity are provisioning inputs, never an environment label. All Hosted hints and a latched private bootstrap row restrict auth. Missing/mismatched identity/origin refuses before startup scheduling. Host and Origin must match; forwarded headers never select reset URLs. CE direct HTTP remains supported when no Hosted binding exists; CE proxies configure an explicit public origin.

Private `issue_bootstrap` is an in-process provisioning primitive, with no issuer API/CLI or startup mint. It requires an empty owned tenant database, configured identity/origin, exact checkout UUID, buyer commitment and payment-transaction commitment. It returns one random bearer secret, hashes it in PostgreSQL and never logs it. Its 30-minute grant is one-use, bound to buyer and tenant, and serializes with both public setup and other grants. Lost issuance/notification requires review, not public-first-user fallback or destructive re-provisioning. It binds a trusted provisioning assertion, not independent proof of payment or buyer truth.

Hosted public setup requires that grant, matching buyer and same-origin request. Ordinary CE initial setup remains available and now serializes first-admin creation. The browser receives a private fragment link; it removes the fragment into memory and submits only to the same-origin setup endpoint. No query-string token or remote service is used in tests.

New logins have persisted session UUIDs and refresh digests. Refresh rotation atomically replaces the digest; replay loses. Logout revokes access/refresh for that session and clears old/new cookie paths. Password changes/reset revoke all sessions. Cookies are HttpOnly/Secure over Hosted, SameSite Strict, path /api/auth, bounded expiry. Stable secrets plus DB records survive restart; rotating secrets invalidates tokens. Old Hosted tokens require login again; legacy CE access tokens retain only their existing expiry, while legacy refresh tokens require login. No claimed global revocation of old CE access JWTs.

Existing users need no bootstrap grant; they need new login after exact-schema migration.
